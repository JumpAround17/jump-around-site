# Site jump-around.net (Jump Around)
Site statique : aucune compilation. Ouvrir index.html ou publier le dossier tel quel.
## Mise en ligne (GitHub Pages, recommandé)
1. Créer un dépôt GitHub (ex. jump-around-site) et y déposer tout le contenu de ce dossier.
2. Settings > Pages > Source : branche main, dossier racine. Le fichier CNAME contient jump-around.net.
3. Chez le registrar du domaine : enregistrements A vers les IP GitHub Pages (voir docs.github.com, « custom domain ») et CNAME www vers <compte>.github.io.
4. Cocher « Enforce HTTPS » dans Settings > Pages.
